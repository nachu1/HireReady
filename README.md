# HireReady – AI Resume Analyzer & Interview Coach

## Overview

HireReady is an AI-powered web application that helps job seekers analyze their resumes, improve their resumes, generate ATS-friendly resumes, create customized cover letters, prepare for interviews, and interact with an AI career assistant.

## Features

- **User Registration & Login** – Secure user authentication.
- **Resume Upload** – Upload resumes in PDF format.
- **AI Resume Analysis** – Analyze resumes using AI.
- **ATS Feedback** – Evaluate resume compatibility and identify areas for improvement.
- **Resume Improvement** – Get AI-powered suggestions to improve resume content.
- **AI Resume Generation** – Generate customized, ATS-friendly resumes.
- **Cover Letter Generator** – Create personalized cover letters based on job requirements.
- **Mock Interview Questions** – Generate interview questions for practice.
- **AI Career Chat** – Interact with an AI assistant for career guidance.
- **Resume PDF Download** – Download generated resumes as PDF files.

## Installation

### Backend Setup

1. Navigate to the backend directory:

   ```bash
   cd backend
   ```

2. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Start the FastAPI development server:

   ```bash
   uvicorn app.main:app --reload
   ```

### Frontend Setup

1. Open a new terminal and navigate to the frontend directory:

   ```bash
   cd frontend
   ```

2. Install the dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

## Environment Variables

Configure the required environment variables for the backend, including your Google Gemini API key and MongoDB connection string.

Keep your API keys and database credentials private. Do not commit your `.env` file to GitHub.
